# Arquivos de identidade visual

| Arquivo | Uso |
| --- | --- |
| `logo.png` | Logo aprovada do gato na lua, PNG transparente 1280 × 1280 |
| `night-shift.ico` | Ícone Windows original, sem alteração |
| `readme-banner.png` | Capa do README, 1280 × 640 |
| `how-it-works.png` / `.svg` | Diagrama do fluxo gerenciado, 1600 × 780 |
| `slim-mode.png` / `.svg` | Ilustração conceitual do modo slim, 1600 × 830 |

A logo e o ICO foram copiados dos assets do aplicativo. A capa foi criada com geração de imagem, usando a logo aprovada como referência. Os diagramas são SVGs editáveis com exportações PNG; no SVG do slim, a logo está incorporada como PNG. Os arquivos não representam capturas de tela nativas. As variantes `.en.png` e `.en.svg` contêm os mesmos diagramas em inglês.

A direção visual usa azul noturno, azul claro e tipografia clara. Referências: fundo `#0B1423`, superfícies `#17283E`, destaque `#91BEE6`, texto `#EAF3FC`.

O ícone slim ilustrado segue as medidas do código: botão 64 × 64, imagem 54 × 54, raio 16, fundo WPF `#AA666A70` (ARGB), contorno `#40FFFFFF`. A figura amplia o ícone apenas para explicá-lo.

A exportação social JPEG está no kit de publicação, fora do repositório. Os nomes de terceiros identificam compatibilidade; estas imagens não usam selos de parceria ou aprovação oficial.
